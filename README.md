# Compound Interest Calculator

A beginner-friendly Python program that calculates compound interest.

## Formula

A = P(1 + r/100)^t

Where:

- P = Principal amount
- r = Rate of interest
- t = Time in years
- A = Final amount

## Features

- Takes principal amount as input
- Takes interest rate as input
- Takes time in years
- Validates user input
- Calculates final balance

## Language

Python
